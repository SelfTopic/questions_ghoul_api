# Спецификация расширения API

Черновик требований к новой версии Questions Ghoul API. Источник — [raw.md](raw.md)
(исходный дамп идей от CheStor), разложенный по темам ниже. Статус: **в процессе
уточнения**, ничего из этого ещё не реализуется.

Главные потребители API: `chestor_bot`, `chestor_site`, в будущем `chestor-bot_site`.

## Файлы

- [question-types.md](question-types.md) — какие форматы заданий должны появиться.
- [topics.md](topics.md) — категоризация вопросов по темам.
- [data-quality.md](data-quality.md) — состояние текущих 500 вопросов и что с ними не так.
- [open-questions.md](open-questions.md) — нерешённые развилки, ждут ответа CheStor.
- [deployment.md](deployment.md) — тестирование в CI и автодеплой тестового стенда на сервер.
- [fandom-data.md](fandom-data.md) — разведка структуры данных на Fandom-вики (для скрапера).
- [question-generation.md](question-generation.md) — как сырые скрапленные данные превращаются в вопросы.

## Что уже решено

- **Медиа-хостинг** (картинки/видео-скрины из вики): пробуем **прямые ссылки на
  Fandom**, без рехостинга — см. [open-questions.md](open-questions.md) п.15.
  Если на практике появятся проблемы (битые ссылки, рейт-лимиты), вернёмся к
  рехостингу/кэш-прокси отдельно.
- **Парсинг Fandom** — отдельный офлайн-пайплайн, не часть runtime API; результат
  кладётся в тот же приватный `assets/data/processed/data.json`, который не попадает
  в репозиторий и в Docker-образ.
